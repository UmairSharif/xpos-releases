# xPOS Releases

Installers for **xPOS Store Server** and **xPOS Register** (Windows).

Download the latest version from [Releases](https://github.com/UmairSharif/xpos-releases/releases/latest):

- `xPOS-Store-Server-Setup-<version>.exe`: the store server (install once per shop)
- `xPOS-Register-Setup-<version>.exe`: a checkout register
- `xPOS-Store-Server-Portable.exe`: run the server without installing

Installed apps update themselves from this page. The `server.yml`, `register.yml` and `.blockmap` files are for the auto-updater; do not rename or delete them.
